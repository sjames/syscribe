Standalone example model demonstrating the native `PlanningItem` element type
(`ADR-SYS-PLANITEM-001`, `REQ-TRS-PLANITEM-000` through `-006`) in one
coherent scenario: the engineering work to add an automatic
Return-to-Home-on-low-battery capability to a small UAV. See `../README.md`
for what each part of this model demonstrates and how to run it.
