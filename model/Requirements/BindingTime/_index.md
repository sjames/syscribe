name: BindingTime
---

Requirements for binding time as a staged-configuration axis: an extensible stage vocabulary,
binding windows on features and parameters, stage-aware Configurations, residual variability,
a generated late-bound parameter file, provenance, projection, verification and UI.

All requirements derive from `REQ-TRS-BT-000` and are governed by `ADR-SYS-BT-001`
(`Decisions::BindingTimeADR`). Extends `REQ-TRS-PARAM-004`.
